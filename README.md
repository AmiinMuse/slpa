# SLPA

Website for the Somaliland Professionals Association of America. Built with Next.js (App Router).

## Development

```bash
npm install
npm run dev
```

The site runs at http://localhost:3000.

## Structure

- `app/` — routes, layout, and global styles
- `app/components/` — shared Header, Footer, and page scaffolding
- `app/icon.png` — SLPA logo, used as the browser tab icon
- `public/slpa-logo.png` — SLPA logo used in the header
- `docs/DESIGN.md` — design notes
